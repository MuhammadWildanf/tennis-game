# tennis-game

Tennis Challenge — web platform + HTTP REST API for Unity (usher-driven queue).

## Run

```bash
npm install
npm start
```

- Player join: `/join` (QR: `GET /qr/join.png`)
- Usher pick: `/queue`
- Venue screen: `/display`
- Admin: `/admin.html`
- Unity contract: `UNITY_API.md` (machine-readable: `GET /api/unity/info`)
